# Zetomate brand: logo kit (Concept 1, the A→Z Path)

The Z is a path. It starts at an orange dot (the idea), zig-zags through the work, and ends at a green coin (money in the bank). That is "From A to Z" in one mark.

Tagline: **From A to Z. You've got a mate.** Sub-line: **Idea to income.**

## Files
- `zetomate-logo.svg` / `zetomate-logo-white.svg`: symbol + name, for the website header and footer (the white version goes on dark backgrounds)
- `zetomate-mark.svg` / `zetomate-mark-white.svg`: the Z path symbol on its own
- `zetomate-app-icon.svg`: app icon or social profile picture
- `favicon.svg`: browser tab icon (no text, so it works without fonts)
- `png/`: PNG versions with transparent backgrounds, plus `favicon-32.png` and `apple-touch-icon.png`

## Colors
| Name  | Hex     | Use |
|-------|---------|-----|
| Mango | #FF6B1A | primary accent, CTAs, the start dot |
| Mint  | #19C98A | success, money, the coin |
| Ink   | #141A33 | text, dark backgrounds |

## Fonts (Google Fonts)
- Headings and logo: **Bricolage Grotesque** (800)
- Body text: **DM Sans** (400/500/700)

The SVGs use live text in Bricolage Grotesque, so load that font on the website. Use the PNGs anywhere the font can't be loaded.
