# Zetomate brand: logo kit (Two Mates, Version B)

The logo shows two "mates": the orange head is the creator and the green head is Zetomate. The Z between them stands for "From A to Z".

Tagline: **From A to Z. You've got a mate.** Sub-line: **Idea to income.**

## Files
- `zetomate-logo-horizontal.svg` / `-white.svg`: main logo for the website header (the white version goes on dark backgrounds)
- `zetomate-logo-stacked.svg` / `-white.svg`: centered logo for hero sections and the footer
- `zetomate-mark.svg` / `-white.svg`: the symbol on its own
- `zetomate-app-icon.svg`: app icon or social profile picture
- `favicon.svg`: browser tab icon
- `png/`: PNG versions with transparent backgrounds, plus `favicon-32.png` and `apple-touch-icon.png`

## Colors
| Name  | Hex     | Use |
|-------|---------|-----|
| Mango | #FF6B1A | primary accent, CTAs, creator |
| Mint  | #19C98A | success, money, payments |
| Ink   | #141A33 | text, dark backgrounds |

## Fonts (Google Fonts)
- Headings and logo: **Bricolage Grotesque** (800)
- Body text: **DM Sans** (400/500/700)

The wordmark in the SVGs uses live text in Bricolage Grotesque, so load that font on the website. Use the PNGs anywhere the font can't be loaded.
